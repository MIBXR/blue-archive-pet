# 制作时保留的提示词

这里逐字节保留 v1.0 源制作目录中的 80 份提示词文件，包含初始模板、逐状态方案、重试与修订文本。目录名称沿用原资料，便于继续沿着某个动作修改。

这些是真实保存的提示词文本，但源任务表仍包含 `pending` 状态；本目录不据此宣称所有文本都曾被成功执行，也不补造调用时间。当前采用的源图以[高清素材索引](../../materials/README.md)和最终成品为准。
