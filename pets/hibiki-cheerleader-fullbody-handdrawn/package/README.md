# 猫冢响 · 拉拉队服全身手绘

v1.0 · 灰黑长发、狗耳与尾巴，青蓝护目镜搭配蓝白拉拉队服和黄白花球。用手绘粗线与二头身比例表现猫冢响的应援姿态。

本包包含可导入的 `spritesheet.png`、名称与描述等信息 `pet.json`，以及 `previews/` 中的逐动作 GIF。

图集采用 sprite v2：1536×2288 像素，8 列×11 行，单格 192×208，包含九种动作和十六个注视方向。作品版本 v1.0 与图集协议版本是两回事。

将本包交给支持 sprite v2 的桌宠应用或 Agent，读取 `pet.json` 后导入原始 PNG。是否启用由你选择；GIF 用于观看动作。

角色来自《蔚蓝档案 / Blue Archive》。参考插画与动作、表情截图由用户提供；部分插画作者尚未确认。角色及参考作品权利归原权利人。
