# 高清网页素材的可复现处理

在已安装 Python 3.10+、Pillow 和 NumPy 的环境中运行：

```bash
python site/tools/prepare-hd.py
```

脚本根据自身位置找到作品仓库；读取 `pets/`，只写入 `site/assets/`，不修改宠物原稿、正式图集或安装包。没有工作区绝对路径、模型调用或新图片生成步骤。

## 透明背景

- 响的 `materials/main.png` 与时的 `selected-sources/waiting.png` 已含有效 alpha，逐字节复制并保留其现有透明度。
- 时的高清主图来自选定的绿底 `selected-sources/base.png`。九动作使用各自选定的原尺寸源条；响另含两个高清注视源条。
- 对不透明绿底或洋红底，先根据背景色差识别背景；只有背景附近的三像素边缘带可以取得部分 alpha，再反算该像素混入的背景颜色。远离背景的白色、发色、cyan 饰件和衣服内部不参与去色，不使用侵蚀删除轮廓。
- 背景孔洞与外部背景采用同样的色差规则，因此分段光环间隙也透明。保存的 PNG 仍保持源图尺寸。

## 帧注册

`motion-hd/{pet}-{state}.png` 保存原尺寸透明源条。部分原稿的角色、尾巴或星星跨越平均分格，因此另生成 `*-registered.png`：根据独立身体及道具的二维连通区域分配像素，软边跟随相邻区域，消除邻帧残影。每个不透明源像素只分配一次，所有 alpha 的总量严格守恒。

注册格宽 600 像素，原稿 Y 坐标保持不变；X 使用同动作共同的等距源网格，避免逐帧根据人物包围框重新居中。网页的统一舞台为 520×520；每个动作只使用一个缩小比例及一个纵向平移，参考人物高度为 340，地面参考线为 460。所有比例不大于 1，不放大伪造分辨率。

响的跳跃原始脚底坐标为 `[698, 648, 616, 661, 695]`；工作应援为 `[592, 593, 592, 593, 535, 593]`。共同地面注册保留这些相对变化，腾空帧不会重新落到地面。时的学兔子五帧脚底均为 565，保留脚不离地的表现。

## 来源与校验

`site/assets/motion-hd/manifest.json` 包含每行原稿路径与 SHA-256、透明源条与注册条 SHA-256、每帧源矩形和绘制矩形、原始网格及身体范围、共同地面和比例。`processing-report.json` 记录背景处理方式、alpha 守恒以及脚底数据。130 帧的强 alpha 范围全部位于网页舞台内。

时没有提供高清转椅原稿，两个转椅方向行继续使用正式 192×208 图集，不从小图放大伪造高清。响的两个高清注视行保持原稿顺序。
