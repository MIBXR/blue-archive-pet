# Hibiki · Cheerleader

把猫冢响的拉拉队服形象做成一只手绘桌宠，让花球、耳朵与小小的跳跃陪伴工作。

## 猫冢响 · 拉拉队服全身手绘

灰黑长发、狗耳与尾巴，青蓝护目镜搭配蓝白拉拉队服和黄白花球。用手绘粗线与二头身比例表现猫冢响的应援姿态。
